How do I get an API key?
  1. Sign up or log in on clist.by.
  2. Open the API page and click the API key link at the top.
  3. You will see a line like this: Authorization: ApiKey yourname:abc123
  4. Put the part before the colon in Username and the part after it in API key, then press Save.

Tip: paste that whole line into the API key field and it is split for you.

How are ratings calculated?

Both sources use Elo: a problem's rating is the skill level at which a contestant would solve it as often as contestants really did.

P(solve) = 1 / (1 + 10^((problem - user) / 400))

Plain numbers come from zerotrac: Elo plus maximum likelihood estimation over contest results. Their code is not published and weekly contests 1-62 are not covered.

Numbers ending in c come from clist.by: each contestant counts by their rating, experienced ones weigh more, and the problem rating is the one where the expected solves match the real number. The formula differs from zerotrac's, so compare them with care.
