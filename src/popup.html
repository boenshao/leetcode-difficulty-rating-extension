How do I get an API key?
  1. Log in to clist.by.
  2. Open the API page and follow the first line to get the key.
  3. Copy the username:key part of the Request header line into the field above.
How are ratings calculated?

Both sources use Elo: a problem's rating is the contestant rating that solves it half the time.

Plain ratings come from zerotrac, Elo with maximum likelihood estimation over contest results. Weekly contests 1-62 are not covered.

Ratings marked with c, like 1275c, come from clist.by, which weights each contestant by their rating. The two formulas differ, so compare them with care.
